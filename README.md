# 龍影 ONLINE

## 起動
1. Node.js 18+ をインストール
2. このフォルダで `npm install`
3. `npm start`
4. ブラウザで `http://localhost:3000` を開く

## 対戦
- プレイヤー1が「ルームを作る」
- 表示された6桁のルームコードをプレイヤー2へ送る
- プレイヤー2がコードを入力して参加
- 2人が同じサーバーへ接続してリアルタイム対戦

## 公開サーバーへ置く場合
HTTPSサイトではWebSocketもWSSで接続する必要があります。リバースプロキシ（Nginx等）でWebSocket Upgradeを通し、`PORT`を設定してNodeサーバーを起動してください。
